🧪 Teste - Sistema de Baixa Imediata no Estoque

Este teste demonstra o novo sistema de baixa imediata implementado nos pedidos de venda.

📋 Como Funciona o Novo Sistema

1. Baixa Imediata: Quando um pedido é salvo, produtos não-SE recebem baixa imediata
2. Controle de Edições: Durante edições, apenas as diferenças são processadas
3. Prevenção de Duplicação: O sistema evita baixas duplicadas em salvamentos recorrentes
4. Produtos SE: Produtos "Sob Encomenda" não recebem baixa automática
