# PraVocê App v5 - Sistema de Gestão Empresarial

Sistema completo de gestão empresarial desenvolvido com React, Vite e TailwindCSS. Inclui módulos para gestão de clientes, fornecedores, produtos, pedidos, colaboradores e muito mais.

## 🚀 Funcionalidades

- **Dashboard Principal** - Visão geral do negócio
- **Gestão de Clientes** - Cadastro e listagem de clientes
- **Gestão de Fornecedores** - Controle de fornecedores e catálogos
- **Gestão de Produtos** - Cadastro e controle de estoque
- **Pedidos de Venda** - Criação e acompanhamento de vendas
- **Ordens de Compra** - Gestão de compras de fornecedores
- **Gestão de Colaboradores** - Controle de funcionários e cargos
- **Gestão de Locais** - Controle de filiais/lojas
- **Painel de Markup** - Cálculo de margens de lucro
- **Sistema de Notificações** - Avisos e alertas

## 🛠️ Tecnologias

- **React 18** - Biblioteca JavaScript para interfaces
- **Vite** - Build tool e servidor de desenvolvimento
- **TailwindCSS** - Framework CSS utilitário
- **React Router** - Roteamento da aplicação
- **React Icons** - Biblioteca de ícones

## 📋 Pré-requisitos

- Node.js (versão 16 ou superior)
- npm ou yarn

## 🔧 Instalação

1. Clone o repositório:
```bash
git clone https://github.com/seu-usuario/pravoceapp-v5.git
cd pravoceapp-v5
```

2. Instale as dependências:
```bash
npm install
# ou
yarn install
```

3. Execute o projeto:
```bash
npm run dev
# ou
yarn dev
```

O projeto estará disponível em `http://localhost:5173`
