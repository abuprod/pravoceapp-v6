🧪 Teste - Ordem de Compra com Produtos SE

📋 Cenário de Teste

Este teste verifica se a ordem de compra está tratando corretamente produtos local SE que não estão cadastrados no sistema.

⚠️ Produtos SE Não Cadastrados

Produtos com local "SE" (Sob Encomenda) que não estão cadastrados no sistema devem:

  • Aparecer na ordem de compra com preço de compra vazio (0)
  • Ter indicação visual de produto não cadastrado
  • Mostrar "Fornecedor não identificado"
  • Permitir edição manual dos dados

🔧 Configuração do Teste

1. Limpar Dados Anteriores

2. Cadastrar Produtos de Teste

3. Criar Pedido de Venda com Produtos SE

4. Simular Criação de Ordem de Compra

5. Verificar Resultado
